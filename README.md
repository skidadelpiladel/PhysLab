What is PhysLab?
Physlab is an interactive physics simulation that lets users and understand the physics that is being applied to things!

What is the goals of PhysLab?
The goal of physlab is to make physics concepts more fun through interactive simulations!
Allow users to change variables and see how it effects the physical motion of an object.
Compare simulations to physcis equations!

First module: One Dimensional collisions
The first module will focus on collisions between two moving objects along a straight line.

Planned feature include:
 - adjust the mass and initial velcotiy of each object.
 - visualising object movement and collisions.
 - comparing velocities before and after collisions.
 - investigating the conservation of momentum.
 -exploring elastic and inelastic collisions.

Technology
 - python 
 - py game 
 - NumPy

Project status
Physlab is currently in early development. The initial focus is on building the foundation for the foundation for the one dimensional collision simulation.

More physics modules may be added as the project develops.
